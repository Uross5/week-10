# Email Validator & Statistics

A Python project for managing users and their email addresses.

The program validates email addresses using regular expressions, calculates email statistics, groups users by domain, checks email length, adds new users, and fixes small email formatting errors.

## Features

- Validate email addresses using Regex
- Count valid and invalid emails
- Count users by email domain
- Display valid and invalid users
- Add new users and prevent duplicate email addresses
- Group users by email domain
- Check email length
- Automatically fix small email formatting errors
- Store user-related information using nested dictionaries
